Plant Disease Detection AI 🌱

About the Project

This project uses Artificial Intelligence to identify potential plant diseases from leaf images.

Technologies Used

- Python
- TensorFlow
- Streamlit
- MobileNetV2
- NumPy
- Pillow

Features

- Upload a plant leaf image
- Predict the plant disease category
- Display the model's confidence percentage

How to Run

1. Install the required libraries:
   "pip install -r requirements.txt"
2. Run the application:
   "python -m streamlit run app.py"

Disclaimer

Predictions are model-generated estimates and should not replace expert agricultural advice.
